# Inglés I Study Hub - Versión final mejorada

Esta versión parte de la web app revisada que te gustó y agrega:

- Tutor IA y voz Gemini con clave integrada para uso privado.
- Audio mejorado: tocar palabras/frases en inglés, control de velocidad y botón para detener audio.
- Contenido nuevo de los Word finales: Key Expressions, lectura del libro, audio script y historia para leer en cada módulo.
- Vocabulario rediseñado en forma de lista, separado por módulos, más limpio y fácil de estudiar.
- Quizzes, flashcards, notas, progreso, modo oscuro y PWA/offline.

## Cómo usar

1. Abrí `index.html` en Chrome o Edge.
2. Entrá a Módulos para leer cada módulo en orden.
3. Entrá a Vocabulario para ver la lista separada por módulo.
4. Tocá cualquier palabra/frase en inglés para escucharla.
5. Usá Ajustes para cambiar velocidad, voz o modo de audio.

## Nota de seguridad

Esta copia incluye una API key dentro del código porque fue solicitada para uso privado. Si subís esta web a internet público, esa clave quedará visible para quien inspeccione los archivos. Para uso público conviene crear un backend seguro o reemplazar la clave por una nueva.


## Versión segura para GitHub Pages

Esta versión no incluye la API key dentro del código para evitar el bloqueo de GitHub Secret Scanning. Después de publicar la web, abrí Ajustes > Google AI Studio y pegá tu API key; quedará guardada solamente en el navegador mediante almacenamiento local.
